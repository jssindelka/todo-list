01 Display type — one decision for you

This is the only fork left in the look. Everything else in the app is monospace either way. A goes literally Nothing: dot-matrix, machine-like, unmistakable. B keeps ref 1's serif headline, which softens the whole screen and reads more editorial. Pick one, or say "A for numbers, B for the greeting" — that hybrid also works.

02 UI type scale

Every UI string is JetBrains Mono, uppercase, widely tracked — ref 1's exact treatment. Task titles are uppercase too, as in the reference; that is the one call worth sanity-checking, since long titles get harder to scan in caps. Numerals use Doto so counts read as a readout.
